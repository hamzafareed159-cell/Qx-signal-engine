# QX Signal Engine

A professional 1-minute binary trading signal engine with multi-confluence analysis and real-time market signal generation.

## Features

✅ **Real-time Signal Generation**
- Live candle clock with alert zone countdown (10 seconds before candle open)
- Multi-timeframe confluence analysis
- Customizable asset pairs & market sessions

✅ **8-Indicator Analysis**
- RSI 14 (Relative Strength Index)
- MACD (Moving Average Convergence Divergence)
- Bollinger Bands
- EMA 5/20 (Exponential Moving Average)
- Stochastic Oscillator
- CCI 20 (Commodity Channel Index)
- ATR (Average True Range)
- Support & Resistance Levels

✅ **Confluence Filters**
- Trend Analysis
- Momentum Confirmation
- Volatility Adaptation
- Signal Confluence Score
- Session Optimization

✅ **Progressive Web App**
- Offline functionality with service worker
- Installable on mobile & desktop
- Home screen shortcut
- Push notifications support

## Asset Pairs Supported

- EUR/USD, GBP/USD, USD/JPY
- AUD/USD, USD/CAD, EUR/GBP
- NZD/USD
- BTC/USD, ETH/USD
- Gold (XAU/USD), Oil (WTI)

## Market Sessions

- London–NY Overlap (Highest volatility)
- London Session
- New York Session
- Tokyo Session
- Sydney Session

## Signal History

Tracks last 6 signals with:
- Asset pair
- Signal type (BUY/SELL/SKIP)
- Confidence percentage
- Candle timestamp

## Usage

1. **Select Configuration**
   - Choose your asset pair
   - Select trading session
   - Set market type (Trending/Ranging/Volatility)

2. **Monitor the Signal**
   - Watch the candle clock progress
   - Alert zone activates at :50 of each minute
   - Signal fires with recommended direction

3. **Enter at Candle Open**
   - Confidence score guides position sizing
   - Strength bars indicate signal reliability
   - History shows previous signals

## Technical Details

- **Language**: HTML5, Vanilla JavaScript
- **Styling**: CSS3 with CSS Variables
- **PWA**: Service Worker caching strategy
- **Architecture**: Client-side only (no backend required)
